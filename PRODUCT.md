# Product

## Platform

Локальная служба командной строки на Python, которую можно подключить как MCP-сервер к любой поддерживаемой ведущей программе.

## Users

Разработчики, которые используют несколько локальных кодовых агентов и хотят выбирать ведущую программу, передавать задачи исполнителям и получать независимые мнения.

## Product Purpose

Мост предоставляет структурированные инструменты для ведущей программы и её исполнителей: Antigravity CLI, Claude Code и OpenCode. Он поддерживает параллельные консультации только для чтения и реализацию в отдельной рабочей копии Git. Ведущая программа проверяет и объединяет изменения.

## Positioning

Небольшой локальный мост без зависимостей, который сохраняет собственные командные оболочки, вход и выбор моделей каждого поставщика. Это не платформа агентов и не облачный сервис.

## Operating Context

Пользователь устанавливает Python 3.9+ и нужные CLI. Выбранная ведущая программа запускает этот файл по протоколу stdio с именем ведущего в переменной `AGENT_ORCHESTRATOR_HOST`. Мост запускает выбранный CLI дочерним процессом и возвращает результат через MCP. Для реализации он записывает текущий `HEAD` исходного проекта, создаёт отдельную ветку и рабочую копию Git и возвращает их состояние вместе с diff.

## Capabilities and Constraints

- Мост использует только стандартную библиотеку Python.
- Поддерживаются Antigravity CLI (`agy`), Claude Code (`claude`) и OpenCode (`opencode`).
- Консультации параллельно запускают от двух до трёх разных агентов в режимах планирования.
- Реализацию выполняет один агент в новой рабочей копии Git; мост не делает слияние и не отправляет ветки на сервер.
- Рабочая копия не является системной песочницей. Дочерние процессы наследуют права пользователя; OpenCode при реализации запускается с автоматическим подтверждением действий.
- Незакоммиченные изменения исходного проекта не переносятся в рабочую копию.
- Учётные данные остаются в соответствующих CLI.
- Вызовы MCP синхронные. Рабочие копии оставляются для проверки; удалять их нужно вручную.
- Проект не утверждает, что параллельные агенты улучшают любую задачу. Делегировать следует независимую и ограниченную работу.

## Brand Commitments

Публичный README написан на английском для широкой аудитории. Внутренние инструкции и комментарии к коду написаны по-русски. Проект не заявляет уровень изоляции выше того, который реально обеспечивает код.

## Evidence on Hand

Исходный код расположен в `src/agent_orchestrator.py`, проверки — в `tests/`. Мост запускался с установленными локальными CLI на macOS; также была проверена реализация задачи в одноразовом Git-репозитории. Учётные данные провайдеров, личные настройки и данные рабочих проектов в репозиторий не входят.

## Product Principles

1. **Ведущая программа отвечает за интеграцию.** Делегированный результат остаётся предложением, пока ведущий не проверил его.
2. **Сохраняй родные CLI провайдеров.** Каждый агент запускается со своим входом и выбором модели.
3. **Разделяй изменения реализации.** Делегированная правка начинается в новой ветке и рабочей копии Git.
4. **Прямо описывай ограничения.** Рабочая копия Git не является песочницей безопасности.

## Accessibility & Inclusion

Продукт не имеет графического интерфейса. Взаимодействие идёт через обычный текст и ошибки JSON-RPC; экранный диктор и поведение терминала зависят от выбранной программы.
