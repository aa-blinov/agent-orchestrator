# Product

<!-- impeccable:product-schema 1 -->

## Platform

Локальная служба командной строки на Python, настроенная как MCP-сервер для Codex CLI.

## Users

Разработчики, которые уже используют Codex CLI и один или несколько локальных кодовых агентов и хотят передавать им задачи без копирования запросов и результатов между терминалами.

## Product Purpose

Мост предоставляет Codex структурированные инструменты для Antigravity CLI, Claude Code и OpenCode. Он поддерживает параллельные консультации только для чтения и реализацию в отдельной рабочей копии Git. За проверку и объединение изменений отвечает Codex.

## Positioning

Небольшой локальный мост без зависимостей, который сохраняет собственные командные оболочки, вход и выбор моделей каждого поставщика. Это не платформа агентов, не облачный сервис и не замена Codex.

## Operating Context

Пользователь устанавливает Python 3.9+, Codex CLI и хотя бы один из поддерживаемых агентских CLI. Codex запускает этот файл по протоколу stdio. Мост запускает выбранный CLI дочерним процессом и возвращает результат через MCP. Для реализации он записывает текущий `HEAD` исходного проекта, создаёт отдельную ветку и рабочую копию Git и возвращает их состояние вместе с diff.

## Capabilities and Constraints

- Мост использует только стандартную библиотеку Python.
- Поддерживаются Antigravity CLI (`agy`), Claude Code (`claude`) и OpenCode (`opencode`).
- Консультации параллельно запускают от двух до трёх разных агентов в режимах планирования.
- Реализацию выполняет один агент в новой рабочей копии Git; мост не делает слияние и не отправляет ветки на сервер.
- Рабочая копия не является системной песочницей. Дочерние процессы наследуют права пользователя; OpenCode при реализации запускается с автоматическим подтверждением действий.
- Незакоммиченные изменения исходного проекта не переносятся в рабочую копию.
- Учётные данные остаются в соответствующих CLI.
- Вызовы MCP синхронные. Рабочие копии оставляются для проверки; удалять их нужно вручную.
- Проект не утверждает, что параллельные агенты улучшают любую задачу. Делегировать следует независимую и ограниченную работу.

## Brand Commitments

Публичный README написан на английском для широкой аудитории. Внутренние инструкции и комментарии к коду написаны по-русски. Проект не заявляет уровень изоляции выше того, который реально обеспечивает код.

## Evidence on Hand

Исходный код расположен в `src/codex_agent_bridge.py`, проверки — в `tests/`. Мост запускался с установленными локальными CLI на macOS; также была проверена реализация задачи в одноразовом Git-репозитории. Учётные данные провайдеров, личные настройки и данные рабочих проектов в репозиторий не входят.

## Product Principles

1. **Codex отвечает за интеграцию.** Делегированный результат остаётся предложением, пока Codex его не проверил.
2. **Сохраняй родные CLI провайдеров.** Каждый агент запускается со своим входом и выбором модели.
3. **Разделяй изменения реализации.** Делегированная правка начинается в новой ветке и рабочей копии Git.
4. **Прямо описывай ограничения.** Рабочая копия Git не является песочницей безопасности.

## Accessibility & Inclusion

Продукт не имеет графического интерфейса. Взаимодействие идёт через обычный текст и ошибки JSON-RPC; экранный диктор и поведение терминала зависят от Codex и выбранного CLI.
